# 🎸 Les Rideaux de Douche (RDD) - Site Officiel

Bienvenue sur le dépôt du site officiel du groupe **Les Rideaux de Douche (RDD)**, groupe de rock alternatif d'Angers des années 90.

## 🌐 Accès au site web

Le site est disponible directement en ligne à l'adresse suivante :
👉 **[https://bacobaco.github.io/rideaux-de-douche/](https://bacobaco.github.io/rideaux-de-douche/)**

---

## 🎶 À propos du projet

Ce site web présente l'histoire, les titres musicaux et les archives du groupe RDD :
- 📻 **Lecteur audio intégré** pour écouter les morceaux et enregistrements du groupe.
- 📜 **Histoire & Membres** : l'aventure musicale d'Angers (Damien Samain, Florent Cadoret, Stéphane Lecompte, Pascal Melot).
- 🎸 **Session 91** et galerie d'affiches de concerts.
- 📖 **Livre d'or interactif** connecté à une API backend.
- 📊 **Compteur de visites** en temps réel.

## 📁 Structure du dépôt

```
.
├── README.md        # Documentation du projet
├── index.html       # Structure HTML5 principale
├── style.css        # Feuillets de style et animations CSS
├── main.js          # Logique JavaScript, lecteur audio & livre d'or
├── audio/           # Fichiers audio MP3
└── images/          # Photos, pochettes et affiches
```

## 🛠️ Exécution en local

Pour consulter le site en local sur votre ordinateur :
1. Ouvrez le fichier `index.html` directement dans votre navigateur web.
2. Ou lancez un serveur local léger (ex. extension *Live Server* sous VS Code ou `npx serve .`).
